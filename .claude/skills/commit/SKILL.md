# Diretrizes de Commit
1. Resuma as alterações atuais utilizando `git diff HEAD`.
2. Escreva uma mensagem de commit clara seguindo o padrão Conventional Commits (ex: feat:, fix:, refactor:, chore:).
3. Execute o comando `git add .` seguido de `git commit -m "sua mensagem"`.
4. Exiba um resumo curto do que foi comitado.
